# Modeling-the-variance-of-SiPMs-in-the-nonlinear-regime-Data

This repository contains the essential data and Monte Carlo code required to reproduce the results of:

- 'Modeling the variance of passive SiPMs in the nonlinear regime', Sensors 26, 5579 (2026), doi:10.3390/s26175579.
- 'An Analytical Charge Dispersion Correction to Non-Paralyzable Dead-Time Models for Passive SiPM Variance' (NDIP26 proceedings, Nucl. Instrum. Methods A, submitted).

Contents:
- `Monte Carlo code`: simulation code, modified from Jha et al., IEEE Trans. Nucl. Sci. 60, 336 (2013).
- `Main figures Data`: data of the figures of the Sensors paper.
- `NDIP26 proceedings data`: simulated data and fitted model parameters of the NDIP26 proceedings.

Specific information regarding the data and Monte Carlo code can be found in the README files inside each folder.
